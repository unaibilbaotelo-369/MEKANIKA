# Car Audio

## Descripción

Simulador de conexiones para los equipos de música del coche. Este recurso digital permite probar y simular diferentes configuraciones de conexión de sistemas de audio automotriz.

## Características

- Simulación de conexiones de equipos de audio
- Configuraciones personalizables
- Interfaz interactiva
